About VerdiAI

VerdiAI is an AI-powered sustainability platform designed to support the Circular Economy by promoting intelligent waste management, resource optimization, and environmentally responsible practices.

The platform enables users to make informed sustainability decisions through AI-driven insights, helping reduce waste, encourage recycling, and maximize resource efficiency. By combining Artificial Intelligence with sustainable development principles, VerdiAI contributes toward creating cleaner communities and a healthier planet.

Getting Started

Clone the Repository

```bash
git clone https://github.com/yourusername/verdi-ai.git
```

Navigate to the Project Folder

```bash
cd verdi-ai
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run the Application

```bash
python app.py
```

Open in your browser

```text
http://127.0.0.1:5000
```
